# VaatePoker

Poker-læringsside. Begrepene er forklart med eksempler, ikke bare listet.

Åpne `index.html`.

## Lær
Hender, posisjon, outs, ordbok (equity, potodds, EV, SPR, MDF, ICM, PKO) og quiz.

## Kalkulatorer
Potodds, preflop-ranges, Hold'em- og PLO5-equity, SPR/MDF/bløff, ICM, PKO, bankroll, OCR.
