# VaatePoker

Poker-læringsside for nybegynnere og viderekomne. Åpne `index.html` i nettleseren.

## Nybegynner
- Håndrangering, 6-max-posisjon, outs (2-og-4) og quiz
- Potodds med impliserte odds
- Preflop 13×13 (UTG / BTN / BB-defend / shove)

## Viderekommen
- Hold'em equity (Monte Carlo)
- SPR, MDF og bløff-/semi-bløff-EV
- Bankroll og ruin-risiko
- ICM (Malmuth–Harville)
- PKO bounty
- PLO5 equity
- OCR fra screenshot

TypeScript-kjernen: `src/lib/poker/`.

## Kjøre
Ingen bygg. Åpne `index.html`.
